# 🤟 SignLingo AR | Learning Basic Sign Language with Augmented Reality ✨

### 📱 About The Project

**SignLingo AR** is an Augmented Reality (AR) mobile application developed as my **Final Year Project (FYP)** 🎓.

The application aims to make learning **American Sign Language (ASL)** more interactive, engaging and enjoyable through AR technology. 🌟

Users can scan specially designed flashcards 🃏 to view animated 3D hand signs representing ASL alphabets (A–Z) and numbers (1–10). The application also features interactive quizzes 📝 and progress tracking 📊 to support the learning experience.

By combining mobile application development, augmented reality and 3D animation, this project explores a more interactive approach to sign language learning. 💡

### 🛠️ Technologies Used
- 🎮 Unity
- 📸 Vuforia
- 📱 ARCore
- 🔥 Firebase
- 🖐️ Blender

### 📌 Project Information
- 🎓 **Project Type:** Final Year Project (FYP)
- 📱 **Platform:** Android
- 🌍 **Language:** American Sign Language (ASL)
- 🔤 **Learning Content:** Alphabets A–Z & Numbers 1–10

💜 *Making sign language learning more interactive, one sign at a time!* 🤟
