## 📱 Application Interface

This section showcases the actual user interface of the SignLingo AR application after the development process. It highlights the main screens and features available in the application, providing an overview of how users interact with the system.

The application interface was developed using Unity, with a focus on providing a simple and user-friendly experience. Each screen is designed to help users navigate through the application and access its learning features easily.

### 1. 🏠 Splash Screen

*The **Splash Screen** serves as the first interface of the SignLingo AR application. It displays the official logo and "Start" button on a bright yellow backdrop, creating a cheerful and welcoming look. The logo and button appear smoothly after the application initializes, ensuring a visually appealing and interactive experience. Clicking the **Start** button takes users to the next screen.*

### 2. 👤 Name List Page

<p align="center">
  <img src="https://github.com/syuhada2808/Pictures/blob/87690e1e2de645764e855517b69e35f8cb20f4d6/App%202.jpg" width="300">

*The Name List Page in SignLingo AR, which appears after the user successfully enters their name on the Name Input Page. The page features a simple and bright yellow background with a clear, user-friendly layout. The main section displays a list of previously entered names, each shown as a button with the name label. At the bottom of the page, there is an Add Name button that allows users to enter a new name.*

### 3. 🤟 Augmented Reality Scene

<p align="center">
  <img src="https://github.com/syuhada2808/Pictures/blob/87690e1e2de645764e855517b69e35f8cb20f4d6/App%203.jpg" width="300">
</p>

*This page is designed to display 3D hand sign models using marker-based AR technology. The 3D model appears when the user points their device's camera at the corresponding flash card. The interface includes features like a zoom slider to adjust the size of the model, a rotate button to view the model from different angles, and a speed slider to control the animation speed. There are also pause/play buttons to stop or resume the animation and an exit button to end the AR session.*

### 4. 📝 SignQuiz Menu

<p align="center">
  <img src="https://github.com/syuhada2808/Pictures/blob/87690e1e2de645764e855517b69e35f8cb20f4d6/App%204.jpg" width="300">
</p>

*The SignQuiz page in the SignLingo AR app provides users with an interactive way to choose quiz levels and track their progress. It includes three main buttons: Easy, Hard, and Progress. The Easy button provides beginner-level questions, while the Hard button offers more challenging questions. The Progress button allows users to view completed quizzes, scores, and correct and incorrect answers. A Back button is also available at the bottom-left corner to return to the main menu. The simple and user-friendly design ensures users can easily navigate between quiz levels and monitor their learning progress.*

### 5. 🎯 Easy Level Quiz Page

<p align="center">
  <img src="https://github.com/syuhada2808/Pictures/blob/87690e1e2de645764e855517b69e35f8cb20f4d6/App%205.jpg" width="300">
</p>

*The Easy Level Quiz page in SignLingo AR is designed to make learning sign language interactive and enjoyable. A timer is displayed at the top of the screen, while a progress tracker shows the current question number, user's score, and quiz level. Users are presented with three answer buttons and receive immediate feedback using green for correct answers and red for incorrect answers. Additional controls include a pause button, exit button, and mute button. After all 10 questions are completed, a result screen appears, showing the user's total score as a percentage and the number of correct and incorrect answers. Users can also retake the quiz using the replay button or return to the main menu using the exit button.*

### 6. 🏆 Progress Tracking

<p align="center">
  <img src="https://github.com/syuhada2808/Pictures/blob/87690e1e2de645764e855517b69e35f8cb20f4d6/App%205.jpg" width="300">
</p>

*This page is designed to display the progress of users' quiz attempts. It lists the results of the Easy Quiz and Hard Quiz, showing the total score, number of correct answers, and wrong answers for each attempt. Each quiz entry is displayed in a clickable panel. By selecting a panel, users can view detailed information about their quiz attempt, including the questions they answered correctly and incorrectly. The page also includes a Back button to return to the previous menu and a Clear Progress button to reset the recorded scores.*
