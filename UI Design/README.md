## 🎨 User Interface (UI) Design

The user interface of **SignLingo AR** was designed to provide a simple, clear and user-friendly experience. The design focuses on making it easy for users to navigate the application and access its learning features. 📱

The interface was planned to support the main functions of the application, including AR sign language learning, quizzes and progress tracking.

### ✨ Design Considerations

- 🎯 **Simple Navigation** – Easy access to the main features of the application.
- 👀 **User-Friendly Layout** – Clear arrangement of buttons, icons and information.
- 📚 **Learning-Focused Design** – Helps users focus on learning ASL alphabets and numbers.
- 📱 **Mobile-Friendly Interface** – Designed for use on Android devices.

### 📲 Interface Design Preview

The following images show the interface designs and planning process of the SignLingo AR application. The design process consists of two main parts: Storyboard and Low-Fidelity Wireframe.

### 1. 📖 Storyboard

The storyboard is an important part of the SignLingo AR development process. It was created to visualize and outline the user's journey when interacting with the application. It serves as a visual guide during the design and development phases by illustrating the application's flow and main functionalities. The storyboard also helps identify potential usability issues and ensures that the application design meets its objectives.
